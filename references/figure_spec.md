## 0 先建立一个判断标准

编辑部初审退稿/退修，图件问题占相当比例，而且几乎都是**可预防的硬性问题**，不是学术问题。判断一张图是否达标，只需四问：

| 检验 | 含义 | 不合格的表现 |
|---|---|---|
| **自明性** | 不看正文也能读懂图在说什么 | 只有图，没有量名单位；图例缺失；(a)(b) 不说明是什么 |
| **可排版性** | 按 1:1 尺寸放进版心后仍清晰 | 出图时 20 cm 宽，排版压到 8 cm，字号从 11 pt 变成 4 pt |
| **可印刷性** | 黑白激光打印后信息不丢失 | 靠红/绿区分类别；浅色细线；灰度相近的色块 |
| **可核查性** | 数据、方法、投影、边界来源可追溯 | 没说投影；没说分级方法；底图来源不明 |

**核心观念**：图是**论证工具**，不是装饰。一张图只承担一个论点。如果一张图需要三段文字才能解释清楚，应该拆成两张图，或者根本不该是图（改成表更合适）。

## 1 图幅与版面：最常见的致命错误

### 1.1 按最终印刷尺寸出图，不要按屏幕尺寸

绝大多数退修意见源于**出图尺寸与排版尺寸不一致**。你在 Jupyter 里用 `figsize=(14, 6)`（英寸）出图，编辑部把图压到半栏 8 cm，字号等比缩小 4 倍，原本 11 pt 的刻度变成 2.75 pt——肉眼不可辨。

**正确做法**：出图时就按最终尺寸设置，字号按印刷后的实际毫米数设定。

| 版式 | 宽度 | 适用 |
|---|---|---|
| 半栏图 | **8 cm** | 单幅、单列、纵向条形图、单张散点图 |
| 通栏图 | **15 cm**（部分刊 16 cm 满版） | 双面板、三联图、地图、时间序列 |
| 最大 | 不超过版心宽度（一般 ≤16 cm） | 复杂组合图 |

用厘米换算常量，不要写英寸小数：

```python
CM = 1 / 2.54
HALF_W = 8 * CM      # 半栏 8 cm
FULL_W = 15 * CM     # 通栏 15 cm

fig, ax = plt.subplots(figsize=(HALF_W, 6 * CM))              # 单图
fig, axes = plt.subplots(2, 2, figsize=(FULL_W, 10 * CM))     # 四面板组合图
```

### 1.2 高度控制

- 单图高宽比建议 0.6–0.75（如 8×5.5 cm）；
- 组合图总高不超过 **10–12 cm**，否则一页放不下图 + 图注；
- 地图类图件受范围长宽比约束，不强求统一高宽比，但同一篇文章内地图范围应一致、比例尺应一致。

### 1.3 图件数量

《地理研究》等刊对图件数量有明确上限（如正文图件一般不超过 8 幅），超限需合并。**合并优于增补**：把 4 张单因子图合并为 1 张 2×2 组合图，信息量不减，版面减半。

### 1.4 组合图的面板排布（课程统一约定）

组合图不是"把几张图拼在一起"，面板排布本身传递结构。同一图幅内**各面板必须等大**，排布按下表统一：

| 子图数 | 排布 | 图幅 |
|---|---|---|
| 1 | 单幅 | 半栏 8 cm 或通栏 15 cm |
| 2 | 1 行 2 列 | 通栏 |
| **3** | **2 行 2 列：第一行 2 幅，第二行 1 幅居中** | 通栏 |
| **4** | **2 行 2 列** | 通栏 |
| 5–6 | 2 行 3 列 | 通栏 |
| ≥7 | 拆成两张图（优先） | — |

关键约定：

1. **4 幅 = 2×2**。不要排成 1×4（每个面板只剩 3.7 cm 宽，刻度挤成一团），也不要一列竖排 4 行（总高超限）。
2. **3 幅 = 2×2 删一格、余下一幅居中**。最忌"第三幅孤悬左下角"——版面重心偏左，右侧留一大块空白，看上去像排版事故。居中面板**只平移、不加宽**，尺寸必须与第一行完全一致。
3. 阅读顺序为 Z 形（左→右、上→下），(a)(b)(c) 编号与之对应，不跳号。
4. 面板间距：`wspace≈0.25–0.35`、`hspace≈0.35–0.45`。太密会挤掉 (a)(b) 标号和 y 轴刻度，太松则面板间视觉断裂。
5. 同一组合图内**同行面板等高、同列面板等宽**，上下行的 x 轴、左右列的 y 轴必须对齐（`tight_layout()` 保证）。
6. 组合图的 `figsize` 总宽取 `FULL_W`，总高 = 单面板高 × 2 + 面板间距，一般 10–12 cm。

3 幅子图的居中版式，标准写法：

```python
# 3 幅子图：2×2，第二行 1 幅水平居中（面板尺寸与第一行完全一致）
fig, axes = plt.subplots(2, 2, figsize=(FULL_W, 11 * CM))
fig.tight_layout()                 # ★ 必须先 tight_layout 再平移
axes[1, 1].remove()                # 删掉右下（或右上）空格
ax3 = axes[1, 0]
pos = ax3.get_position()
ax3.set_position([(1 - pos.width) / 2, pos.y0, pos.width, pos.height])
```

> **注意顺序陷阱**：`tight_layout()` 会按 gridspec 网格重新排布所有面板，**撤销 `set_position()` 的效果**。所以必须先 `tight_layout()`、后删除空格并平移；`savefig(bbox_inches="tight")` 不会再改变面板相对位置，只裁白边。
>
> 课程模板中已封装为 `center_bottom_left(fig, axes)`（见第 10 节），直接调用即可。

## 2 字体：中文宋体，数字英文 Times New Roman

### 2.1 规则

| 字符类型 | 字体 |
|---|---|
| 汉字 | **宋体（SimSun）** |
| 数字、英文、单位符号 | **Times New Roman** |
| 数学符号、公式变量 | Times New Roman 斜体（`$x$`，mathtext 用 STIX 与 TNR 风格一致） |
| **禁用** | 黑体、微软雅黑、楷体做正文标注；Arial/DejaVu 混入 |

注意：图内文字**不用黑体**。黑体只用于图外的大标题（而高质量期刊正文一般不设图内标题，见第 3 节）。

### 2.2 实现：逐字形回退

matplotlib ≥3.6 支持按字形逐个回退：字体列表里第一个字体没有该字形时，自动落到下一个。所以把 Times New Roman 放第一位、SimSun 放第二位，就能实现"英文数字走 TNR、汉字走宋体"，无需任何手工切换：

```python
plt.rcParams["font.family"] = ["Times New Roman", "SimSun"]
```

前提是本机确实装了这两种字体（Windows 自带）。

### 2.3 字号（按印刷后实际大小）

| 元素 | 字号 |
|---|---|
| 坐标轴标目（量名称/单位） | **9 pt** |
| 刻度标签 | **8 pt** |
| 图例文字 | **8 pt** |
| 面板编号 (a)(b)(c) | **8 pt** |
| 图内数据标注 | 7–8 pt，能省则省 |

原则：**字号在代码里全局设定，不逐图手写 `fontsize=`**。否则 12 张图 12 套字号，全文不一致。

## 3 图题与图注：图内不设标题

### 3.1 铁律

**图内不得有 `set_title` / `suptitle`。** 图题、说明、结论一律放在图**下方**的图注里，由排版系统统一处理（图注字号、行距、居中式样全刊统一）。

理由：
1. 图内标题会与正文图题重复，双份信息浪费版面；
2. 图内标题字号难以与全刊图注统一；
3. 图被缩放/裁切后标题位置会乱；
4. 中文期刊的图注还承担**解释面板、说明符号、标注来源**的职责，图内放不下。

### 3.2 图注格式

```markdown
> **图4**　(a) 性别、(b) 舱位等级、(c) 登船港口、(d)(e) 同船亲属数分组下的生还率，
> 虚线为整体基准生还率 38.4%。Sex 的组间差异最大，是最强的单因子；
> SibSp 与 Parch 呈倒 U 型，暗示"家庭规模"存在最优区间。
>
> **Fig. 4**　Survival rate by (a) sex, (b) passenger class, ...
```

要素齐全的图注包含四段：

| 段 | 内容 | 示例 |
|---|---|---|
| ① 编号 + 总述 | 图几，一句话说这张图是什么 | 图4　各因子分组下的生还率 |
| ② 面板释义 | 每个 (a)(b)(c) 是什么 | (a) 性别、(b) 舱位等级 |
| ③ 符号约定 | 虚线、误差棒、阴影、颜色的含义 | 虚线为整体基准值；误差棒为标准差 |
| ④ 结论性解读 | 从图中能读出什么（1–2 句） | Sex 组间差异最大…… |

补充要求：
- **中英文对照**：多数核心刊要求中文图题 + 英文图题（Fig. X），投稿时一并给出；
- **数据来源**：地图、遥感影像、统计年鉴类图件必须在图注末注明来源；
- **基金标注**不写进图注，放首页脚注。

### 3.3 面板编号

组合图必须有 `(a)(b)(c)`，且**位置全篇统一**——面板**上方外侧左上角**：

```python
ax.text(0.03, 1.04, "(a)", transform=ax.transAxes,
        ha="left", va="bottom", fontsize=8)
```

放在面板内部会压住数据（尤其散点图、条形图顶部），放在上方外侧既统一又不遮挡。全篇 12 张图必须用同一个坐标，不能有的在图内、有的在图外。

### 3.4 图的编号与正文引用

- 图按**正文首次引用顺序**编号；图随文走，**不先于引用出现**；
- 正文必须逐一引用每一张图（"见图 4""如图 4(a) 所示"），**未被引用的图一律删除**——图是论证的一环，不是附件；
- 引用时指明面板：结论落在哪个 (a)(b)(c)，就引用哪个面板，不笼统写"如图 4 所示"；
- 图与其对应的分析段落就近排版，不跨节；
- 全文同一张图不重复编号；修订稿中新增图插在合适位置并**全局重排编号**，不能出现"图 4-1"式补丁编号。

## 4 坐标轴与标目

### 4.1 标目写法：「量名称/单位」

中文期刊的强制格式是**斜线分隔的量/单位**，不用括号：

| ✅ 正确 | ❌ 错误 |
|---|---|
| `生还率/%` | `生还率 (%)`、`Survival rate (%)` |
| `海拔/m` | `海拔（米）` |
| `人口密度/(人·km⁻²)` | `人口密度(人/平方公里)` |
| `降水量/mm` | `降水(mm)` |
| `年份` | `年份/年`（无量纲的时间轴写"年份"即可） |

要点：
- 单位用**正体**，量的符号用**斜体**（`$T$/℃`）；
- 复合单位用负指数或中点：`(人·km⁻²)`、`(m³·s⁻¹)`；
- 单位前的斜线只出现一次：`(kg·m⁻³)` 不写成 `kg/m/m/m`；
- 无量纲/计数类用 `/人`、`/个`、`/%`、`/£`；
- 对数轴在标目或刻度上标明：`ln(1+票价)/£` 或刻度写 `10⁰ 10¹ 10²`。

### 4.2 刻度

```python
plt.rcParams.update({
    "xtick.direction": "in", "ytick.direction": "in",   # 朝内
    "xtick.top": True, "ytick.right": True,            # 四周齐全
    "xtick.major.size": 3, "ytick.major.size": 3,
    "xtick.minor.visible": False,
    "axes.linewidth": 0.8,
})
```

- 刻度**朝内**（这是中文期刊与多数国际刊的共同惯例）；
- **四周均有刻度线**（上、右边框也要有），形成封闭图框；
- 刻度线长 3 pt 左右，框线 0.5–0.8 pt；
- 不用灰底网格（`style="ticks"`），需要辅助线时用浅灰实线并极细。

### 4.3 坐标范围与断轴

- y 轴不从 0 起时，**必须在图注中说明**，否则构成视觉夸大；
- 条形图的 y 轴必须从 0 起（长度编码的固有要求），折线/散点可截断但需说明；
- 跨数量级用对数轴，不用断轴（断轴在中文刊中审稿人普遍反感）；
- 分类轴标签过长时用换行，不要斜排 45°（斜排不可读）。

### 4.4 组合图的共享坐标轴

组合图各面板量纲相同时必须共享坐标轴，避免同一含义出现两套刻度：

```python
fig, axes = plt.subplots(2, 2, figsize=(FULL_W, 10 * CM), sharey="row")
```

- `sharex="col"`：同列共享 x 轴；`sharey="row"`：同行共享 y 轴；
- 共享后内部面板的重复刻度标签自动隐藏，属正常现象；标目只写在**最外侧**面板；
- 各面板数据范围差异过大（超过一个数量级）时**不要强行共享**，分面板独立刻度并各自标目，否则小值序列会被压成直线。

### 4.5 双 y 轴：能不用就不用

双 y 轴（`twinx()`）在中文期刊中审稿人普遍反感：左右两套刻度容易造成虚假的因果暗示与读图歧义。确需使用时：

- 左右轴标目与对应曲线**用同一颜色标出**（轴、刻度、曲线同色），并在图注说明"左轴对应××，右轴对应××"；
- 两个量必须有可比的时间/空间基准，且正文明确说明双轴带来的读图风险；
- **三个及以上 y 轴一律禁止**，改拆面板。

### 4.6 数字与符号排版细节（全篇统一）

| 项 | 规范 | 示例 |
|---|---|---|
| 负号 | `axes.unicode_minus=False`，统一用连字符渲染，避免宋体缺 U+2212 字形出方块 | -0.15 |
| 百分号 | 紧贴数字，不空格 | 38.4% |
| 千分位 | 四位以上加千分位符，全篇统一（中文刊常用空格） | 14 044 |
| 小数 | 保留前导 0（0.87 不是 .87）；同一列小数位一致 | 0.87 |
| 范围 | 用一字线"—"，不用"~"或"-" | 25—30 ℃ |
| 日期 | 全篇统一格式 | 2026-10-28 |

## 5 图例与符号

| 项 | 要求 |
|---|---|
| 边框 | **无边框**（`frameon=False`），期刊不用方框圈图例 |
| 位置 | 优先放在数据空白区，或坐标范围外的右侧；避免压在数据上 |
| 顺序 | 与图中元素出现顺序一致（左→右、上→下）；表示有序类别时按等级排 |
| 命名 | 与正文、表格用词完全一致（正文叫"随机森林"，图例就不能叫"RF"） |
| 多图共用 | 多面板共用同一图例时，只画一次（放在组合图右侧或底部） |

符号规范：
- 同一篇文章内符号语义必须稳定（▲ 不能在图 2 表示观测值、图 5 表示预测值）；
- 点符号大小 4–6 pt，线宽 0.8–1.2 pt，标记边缘线 0.5 pt；
- 误差棒必须说明是标准差（SD）、标准误（SE）还是 95% 置信区间——**这是高频退修点**。

### 5.1 色标（colorbar）规范

- colorbar 的标目同样用「量名称/单位」，字号与坐标标目一致（9 pt）；
- 同一组合图内各面板**使用同一色标范围**：`vmin`/`vmax` 必须显式指定（不能各面板各自动取值域），并**共用一个 colorbar**；确因量纲不同无法统一时，逐面板标注各自范围；
- colorbar 高度与面板等高，宽度取面板宽的 0.03–0.05 倍，放在整幅组合图最右侧居中；
- 分级设色的 colorbar 用离散色块、刻度落在分级断点上，不用连续渐变模拟离散分级。

```python
vmin, vmax = data.min(), data.max()          # 全局范围，所有面板共用
im = axes[0].scatter(x, y, c=data, vmin=vmin, vmax=vmax, cmap="RdBu_r")
cbar = fig.colorbar(im, ax=axes.tolist(), shrink=0.9, pad=0.02)
cbar.set_label("残差/$m", fontsize=9)
```

### 5.2 图内文字标注

- 条形图末端标数值与轴刻度**二选一**：已有刻度标签就不必逐条标值（信息重复）；
- 标注不压线、不压点，放在数据点上方或右侧错位处；密集序列只标首、尾、极值；
- 显著性标记：`*`/`**`/`***` 置于比较组上方横线（bracket）中央，含义写图注；
- 图内标注文字同样遵循第 2 节字体规则；图内只放**短标签**，不放完整句子——句子留给图注。

## 6 色彩：先保证黑白可读

### 6.1 三条硬指标

1. **灰度可分**：转成灰度后，任意两个相邻色阶的灰度差 ≥ 10%（用 ImageJ 或 Photoshop 检查）；
2. **色盲友好**：避免红-绿配对（约 8% 男性红绿色弱）；改用红-蓝、橙-蓝；
3. **色阶有序**：连续型变量用单调色带（`viridis`、`RdBu_r`、`YlOrRd`），**不用彩虹色带 `jet`**——jet 不是感知均匀的，会凭空造出虚假的"边界"。

### 6.2 分类 vs 连续

| 数据类型 | 配色 | 示例 |
|---|---|---|
| 分类（无序） | 定性色板，≤6 类，类别多时用形状+颜色双编码 | `tab10`、`Set2` |
| 有序分级 | 单色相渐变（浅→深） | `Blues`、`YlOrRd` |
| 正负偏离 | 双向发散色板，以 0 为白/中灰 | `RdBu_r`、`coolwarm` |
| 强调/对比 | 主色 + 灰 | 目标系列着色，其余灰化 |

### 6.3 色彩空间

- 期刊排版用 CMYK，屏幕用 sRGB。**高饱和纯色（#FF0000、#00FF00）在 CMYK 中会明显变暗**，印刷后失去区分度；
- 建议用**中等饱和度**的配色（如 `#D85A30`、`#185FA5`、`#0F6E56`、`#534AB7`），既能在屏幕区分，也能在印刷保留；
- 若期刊只收灰度图（少数刊部分栏目），出图阶段就要按灰度设计。

### 6.4 线型与标记：黑白打印仍可辨

颜色不能是类别信息的唯一载体。同一张图内的多个系列必须**颜色 + 线型 + 标记三重编码**，黑白打印后靠线型和形状仍能区分：

| 系列 | 推荐组合 |
|---|---|
| 第 1 系列 | 实线 `-` + 实心圆 `o` |
| 第 2 系列 | 虚线 `--` + 空心方块 `s`（`markerfacecolor="white"`） |
| 第 3 系列 | 点划线 `-.` + 实心三角 `^` |
| 第 4 系列 | 点线 `:` + 空心圆 `o` |

- 系列 ≥5 个时优先拆图，而不是继续叠加样式；
- 同一篇文章内各图的系列样式必须稳定：图 2 的"随机森林"是红色实线圆点，图 5 就不能变成蓝色虚线方块；
- 面积填充类（堆叠图、置信带）无法用线型区分，改用透明度 + 边界线区分，并做灰度检查。

## 7 输出格式与分辨率

### 7.1 矢量优先

| 格式 | 用途 | 说明 |
|---|---|---|
| **PDF** | 首选，投稿通用 | 矢量，可无损缩放；需嵌入字体 |
| **EPS** | 部分刊要求 | 矢量，兼容老排版系统 |
| AI / CDR | 需编辑时 | 编辑部可能要求提供源文件 |
| PNG | 校对、网页、PPT | 位图，600 dpi |
| TIFF | 部分刊要求 | 位图，LZW 无损压缩，600 dpi |
| **JPG** | **禁用** | 有损压缩会在文字边缘产生噪点 |

### 7.2 双格式同时导出

投稿要矢量、校对要位图，一次输出两份：

```python
def savefig(fig, filename: str, dpi: int = 600) -> Path:
    """矢量 PDF（投稿）+ 600 dpi PNG（校对），同时行内显示。"""
    stem = filename.rsplit(".", 1)[0]
    for path in (FIG / f"{stem}.pdf", FIG / filename):
        fig.savefig(path, dpi=dpi if path.suffix == ".png" else None,
                    bbox_inches="tight", facecolor="white")
    plt.show()      # inline 后端会自动关闭 figure，实现图既落盘又行内可见
    print(f"  已保存 → figures/{stem}.pdf, figures/{filename}")
    return FIG / filename
```

### 7.3 分辨率

| 图类型 | 最低分辨率 |
|---|---|
| 线条图（折线、散点、条形、示意图） | **600 dpi** |
| 连续调（遥感影像、晕渲、照片） | **300 dpi** |
| 含小字的组合图 | 600 dpi（保证 7 pt 字可辨） |

### 7.4 字体必须嵌入，且不能是 Type3

PDF 里如果字体是 **Type3**（位图化的伪字体），说明文字已变成图形，编辑无法重排、印刷会模糊。设置：

```python
plt.rcParams["pdf.fonttype"] = 42      # TrueType 嵌入
plt.rcParams["ps.fonttype"] = 42
```

验证方法（检查 PDF 二进制）：

```python
import re
raw = open("fig.pdf", "rb").read()
print(sorted(set(re.findall(rb"/BaseFont\s*/([A-Za-z0-9+\-_,#]+)", raw))))
print("含 Type3:", b"/Subtype /Type3" in raw or b"/Type3" in raw)
print("字体已嵌入:", b"/FontFile2" in raw or b"/FontFile3" in raw)
```

达标输出示例：`TimesNewRomanPSMT` + `SimSun`，`Type3=False`，`嵌入=True`。

### 7.5 出血与白边

`bbox_inches="tight"` 会自动裁掉多余白边，但会**改变最终物理尺寸**（15 cm 的通栏图可能变成 14.8 cm）。若期刊严格要求尺寸精确，改用 `fig.subplots_adjust()` 手动控制边距，或 `pad_inches=0`。

## 8 表格：三线表

图之外，表格同样有硬规范。

### 8.1 三线表

只保留三条横线：顶线、表头下线、底线（必要时加辅助线）。**无竖线，无外框**。

```markdown
**表3**　三种模型的交叉验证结果

| 模型 | 5 折 CV AUC | 过拟合间隙 | 训练耗时/s |
|:---|---:|---:|---:|
| 逻辑回归 | 0.872 ± 0.011 | 0.005 | 0.4 |
| 随机森林 | 0.868 ± 0.009 | 0.163 | 3.2 |
| 决策树 | 0.845 ± 0.014 | 0.036 | 0.1 |
```

### 8.2 表题在上，图题在下

这是中文期刊的固定位置规则：**表题在表上方**，**图题在图下方**。别弄反。

### 8.3 数值与空缺

| 项 | 规范 |
|---|---|
| 小数位 | 同一列统一（0.872 / 0.868 / 0.845，不混用 0.87 与 0.8720） |
| 有效数字 | 均值 ± 标准差保留同位数：`0.872 ± 0.011` |
| 空缺 | **无数据用"—"（长破折号）**，不是 0、不是空白、不是 NaN |
| 零值 | 写 `0`，与"—"区别开 |
| 显著性 | `* P < 0.05`、`** P < 0.01`，星号含义写表注 |
| 单位 | 放表头：`AUC` 无量纲；有量纲写 `面积/km²` |
| 千分位 | 四位以上数字加千分位空格或逗号，全篇统一 |

### 8.4 导出

## 9 地图类图件的额外要求（地理学论文的关键分）

地图不是"带底图的散点图"，它有独立的制图规范与**法律合规要求**。

### 9.1 必备要素（缺一即退修）

| 要素 | 要求 |
|---|---|
| **图廓** | 封闭图框，经纬网或方里网，网格注记 |
| **指北针** | 简单箭头即可，放在图廓内右上角空白处 |
| **比例尺** | 数字比例尺 + 线段比例尺；同一文章内所有地图比例尺应一致 |
| **图例** | 分级标准、符号含义、色带数值 |
| **经纬网注记** | 格式 `110°E`、`35°N`，间隔取整（1°、2°、5°） |
| **投影说明** | 在图注中写明投影，如"Albers 等积圆锥投影（中央经线 105°E，标准纬线 25°N、47°N）" |
| **数据来源** | 底图来源、专题数据来源分列注明 |

### 9.2 投影选择

| 研究范围 | 推荐投影 |
|---|---|
| 全国 | Albers 等积圆锥（标准纬线 25°N / 47°N，中央经线 105°E） |
| 省域/流域 | Albers 或 Lambert 等角圆锥，按范围设定中央经线 |
| 城市/小区域 | UTM（选对带号）或高斯-克吕格 3° 带 |
| 全球 | Robinson 或 WGS84 经纬度（须说明经纬度网格不等距） |

**不要**直接拿 EPSG:4326 经纬度坐标当平面坐标画面积、算密度、量距离——高纬度地区形变可达数倍。计算前必须投影到等积坐标系（面积）或等距坐标系（距离）/等角（方位）。

### 9.3 分级方法必须交代

分级设色图的图例不能只画色块，还要说明分级依据：

| 方法 | 适用 |
|---|---|
| 自然断点（Jenks） | 数据分布有明显聚集，常用默认 |
| 分位数 | 各级样本数相等，适合强调排名 |
| 等间距 | 数据均匀分布或需要可比的绝对阈值 |
| 几何间隔 | 跨数量级数据 |
| 手动断点 | 有国家标准/业务阈值（如 PM2.5 的 35、75 μg/m³） |

图注写："按自然断点法分为 5 级"。同时注明分级数（3–7 级为宜，超过 7 级人眼无法区分）。

### 9.4 中国地图的合规红线（必须遵守）

依据《地图管理条例》，公开出版、发表的地图必须符合国家有关规定：

1. **完整表示领土**：中国全图必须完整表示南海诸岛、台湾岛、钓鱼岛及其附属岛屿等，**不得漏绘、错绘**；
2. **界线画法**：国界线按国家标准画法，不得将未定国界画为已定国界；不得错绘藏南、阿克赛钦等地区；
3. **使用标准底图**：优先使用自然资源部**标准地图服务系统**（`bzdt.ch.mnr.gov.cn`）下载的底图，或经审核的公开版地理底图；
4. **审图号**：公开使用的地图需取得审图号，在图廓外标注 `审图号：GS(20XX)XXXX号`。使用标准地图并直接引用时，按标准地图使用说明执行；
5. **示意图同样受约束**：即使只是"研究区示意图"，只要出现国界，就受同一规范约束——**不能用随手找的 shp 文件**；
6. **不标注敏感信息**：不标注军事禁区、涉密设施、未公开坐标。

> 实操建议：论文里任何一张带国界或省界的图，底图都从标准地图服务系统取，并在图注写"底图来源：自然资源部标准地图服务系统（审图号 GS(20XX)XXXX号），边界无修改"。

### 9.5 空间数据的其他规范

- **分辨率与比例尺匹配**：1 km 栅格不能画成 1:5 万比例尺；图注注明栅格分辨率；
- **MAUP**：同一数据在省/市/县三级单元上做分级设色，结论可能不同——多尺度结论要一并呈现或说明选择理由；
- **色带方向**：不可加性指标（比率、密度）与可加性指标（总量）配色逻辑不同，前者用发散或单色相，后者可用单色相渐变；
- **无数据区**：用浅灰填充并在图例中标注"无数据"，不要留白（留白会被误认为数值最低）。

def panel(ax, tag: str) -> None:
    """面板编号：统一置于面板上方外侧左上角。"""
    ax.text(0.03, 1.04, tag, transform=ax.transAxes,
            ha="left", va="bottom", fontsize=8)


def center_bottom_left(fig, axes) -> None:
    """3 幅子图的 2×2 版式：第二行 1 幅水平居中，面板尺寸与第一行完全一致。

    ★ 必须在 fig.tight_layout() 之后调用——tight_layout 会撤销 set_position。
    """
    ax = axes[1, 0]
    axes[1, 1].remove()
    pos = ax.get_position()
    ax.set_position([(1 - pos.width) / 2, pos.y0, pos.width, pos.height])


def save_table(df, filename: str) -> Path:

## 11 常见退修意见与对应处理

| 编辑部意见 | 根因 | 处理 |
|---|---|---|
| 图内文字过小，印刷后不可辨 | 按屏幕尺寸出图，排版被压缩 | 按 8/15 cm 出图，字号 8–9 pt |
| 图件模糊、有锯齿 | 位图分辨率不足或用了 JPG | 改矢量 PDF；位图 600 dpi |
| 图中中文为方块/乱码 | 字体未设或未嵌入 | 设 SimSun；`pdf.fonttype=42` |
| 图中英文与中文风格不统一 | 中文用了黑体/英文用了 Arial | 宋体 + TNR，全局 rcParams |
| 坐标轴缺少单位 | 只写量名称 | 改「量名称/单位」 |
| 图例压在数据上 | 未留白或未调位置 | 加 `ylim` 留白，或 `bbox_to_anchor` 外置 |
| 图中含标题，与图题重复 | 用了 `set_title` | 删除，信息移入图注 |
| 组合图 (a)(b) 未说明 | 图注缺面板释义 | 图注补 (a)…(b)… |
| 3 幅组合图最后一幅孤悬左下角 | 直接排 2×2 未居中 | 删空格、左下格水平居中（见 1.4） |
| 组合图各面板大小不一 | 手动拼图、无统一网格 | `subplots`/`GridSpec` 统一面板尺寸（见 1.4） |
| 重复刻度、面板间刻度不一致 | 未设共享坐标轴 | `sharex="col"`/`sharey="row"`（见 4.4） |
| 双 y 轴读图歧义 | 左右轴与曲线无对应 | 左右轴按曲线着色并在图注说明（见 4.5） |
| 多面板色标范围不一致 | 未显式指定 vmin/vmax | 全局范围、共用一个 colorbar（见 5.1） |
| 黑白打印后系列不可辨 | 只用颜色区分 | 线型 + 标记 + 颜色三重编码（见 6.4） |
| 误差棒未说明含义 | 缺符号约定 | 图注写"误差棒为标准差（n=5）" |
| 颜色印刷后无法区分 | 红绿配对 / 高饱和 | 改红蓝、降饱和度，做灰度检查 |
| 缺少投影/比例尺/指北针 | 地图要素不全 | 按 9.1 补齐 |
| 国界/境界画法不规范 | 底图来源不合规 | 换标准地图底图，标注审图号 |
| 分级依据不明 | 未说明分类方法 | 图注写"自然断点法，5 级" |
| 图件数量超过上限 | 未做合并 | 组合为多面板图 |
| 图未在正文引用 | 图当附件拼凑 | 逐图引用，未引用的删除（见 3.4） |
| 表格有竖线/外框 | 用了 Excel 默认样式 | 改三线表 |

## 附：本课程的执行约定

四周所有 Notebook 统一执行本规范，具体落在：

| 项 | 约定 |
|---|---|
| 初始化单元 | 复制第 10 节模板，`sns.set_theme` 在前、字体在后 |
| 图内标题 | 一律不用，图题写在图下 markdown 图注（`> **图N**　…`） |
| 面板编号 | `panel(ax, "(a)")`，位置 `(0.03, 1.04)`，`va="bottom"` |
| 组合图版式 | 4 幅 2×2；3 幅 2×2 第二行居中：先 `tight_layout()` 再 `center_bottom_left(fig, axes)` |
| 图幅 | 单图 `HALF_W`，多面板 `FULL_W`；同图各面板等大、坐标对齐 |
| 输出 | `savefig()` 双格式 + `plt.show()`，图既行内可见又落盘 `figures/` |
| 命名 | 图 `W{N}_fig{两位序号}_{英文短名}.png`；表 `W{N}_tab{两位序号}_{英文短名}.csv` |
| 表格 | `save_table()`，`utf-8-sig` |
